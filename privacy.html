ChakuChaku Privacy Policy

Effective date: August 19, 2026

What ChakuChaku stores

ChakuChaku stores your study progress, answer history, SRS state, and display preferences on your device. ChakuChaku has no user accounts, advertising, or analytics, and the developer does not receive this data.

Progress backups

When you export a progress backup, you choose where to save or share the JSON file. Import only reads the file you select. Backups contain study progress and preferences; they do not contain an OpenAI API key.

Optional AI autocorrection

AI autocorrection is off by default. If you enable it and provide your own OpenAI API key, ChakuChaku sends your answer and the relevant exercise context directly to OpenAI for assessment. The key is kept only for the current app or browser session and is not included in backups. Requests disable response storage and API data is not used for model training by default, but OpenAI may retain abuse-monitoring logs containing prompts and responses for up to 30 days. OpenAI processes this content under the privacy and security protections of its API terms and does not receive it for advertising or tracking. Review OpenAI's API data controls before enabling the feature.

Notifications and audio

On mobile, ChakuChaku asks for notification permission only if you enable the optional daily review reminder. The reminder is scheduled locally on your device. Lesson audio is bundled with the mobile app and cached on demand by the web app.

Data deletion

Use Settings → Reset learning progress to delete local SRS data and answer history. Uninstalling the mobile app or clearing this site's browser data also removes locally stored data. Turning off AI autocorrection stops future transfers. Any request about content already processed by OpenAI must be made through the controls for the OpenAI organization that owns the API key.

Contact

For privacy questions, open an issue in the ChakuChaku repository.
